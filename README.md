# Jero Jones · Design System

Design system de la web del artista, el micrositio de la experiencia transmedia y la app de RA: tokens, componentes, contexto, assets y guías de uso.

Es una página única y autocontenida (`index.html`): las fuentes de alternativa, las imágenes y los estilos están incluidos, así que se abre directo en el navegador, sin servidor ni dependencias.

## Contenido

1. **Tokens:** colores, tipografía, espaciado, formas y tamaños.
2. **Componentes:** 18 componentes con sus estados.
3. **En contexto:** los componentes combinados en pantallas reales.
4. **Assets:** recursos compartidos entre apps.
5. **Guías de uso:** cuándo usar cada color, estilo de texto, token y componente.

## Tipografía

Opción principal: Helvetica Neue y Helvetica Neue Condensed, si están instaladas en el equipo. Alternativa: Roboto y Roboto Condensed, incluidas en la página.

## Ver la página

Abrí `index.html` en el navegador. Si el repositorio tiene GitHub Pages activado (Settings > Pages > rama `main`, carpeta raíz), también se ve online.
